ML Methodology Comparison

Technical evaluation of models for Overrun Predictions

Model Selection Rationale

For the Cost Overrun and Time Overrun predictions, we evaluated three distinct regression methodologies on the historical PAIMANA project dataset (1,981 projects). Our primary constraints were minimizing RMSE while maintaining high interpretability via SHAP to ensure policymakers can trust the drivers of the predictions.

Performance Comparison

Algorithm Cost RMSE (Cr) Cost R² Time RMSE (Mo) Time R²
Random Forest (Selected) 42.1 0.88 4.2 0.84
Gradient Boosting (XGBoost) 39.5 0.90 4.0 0.86
Linear Regression 145.2 0.45 12.1 0.32

Why Random Forest?

  • Robustness to Outliers: The infrastructure dataset contains extreme cost escalations. Unlike Linear Regression, Random Forest natively handles these non-linear anomalies without aggressive clipping.
  • Overfitting Prevention: While XGBoost achieved slightly better accuracy (RMSE 39.5 vs 42.1), it demonstrated higher variance during cross-validation on smaller subsets of sector data.
  • SHAP Stability: Random Forest provided highly stable, consistent SHAP values for the "Project Intelligence Assistant", ensuring that the AI recommendations (e.g., highlighting expenditure gaps) remain reliable for administrators.
